# Fonts

`InterVariable.woff2` is the unmodified variable web font from [Inter 4.1](https://github.com/rsms/inter/releases/tag/v4.1) by The Inter Project Authors. It is self-hosted so the deck renders with the same metrics for every viewer, in exports, and in `npm run inspect`, without requests to a third-party font service. The variable font covers the in-between weights the deck uses, such as 650 and 750.
